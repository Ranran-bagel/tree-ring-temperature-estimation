# Tree-Ring Temperature Estimation

## Description

This project explores whether historical temperatures
can be estimated from tree-ring width data.

The research question was proposed as part of
a university group assignment.

Python was used to analyze the relationship between
tree-ring growth and historical temperature records.

## Technologies

- Python
- pandas
- NumPy
- Matplotlib
- statsmodels

## Methodology

1. Collect tree-ring and temperature data.
2. Preprocess and visualize the datasets.
3. Calculate correlations between tree-ring width
   and temperature.
4. Fit simple and multiple linear regression models
   using Ordinary Least Squares (OLS).
5. Estimate historical temperatures.
6. Analyze regression results and limitations.

## Data Sources

- J-STAGE Data: Tree-ring width dataset
- Japan Meteorological Agency: Historical temperature data
